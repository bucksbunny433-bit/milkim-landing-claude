# Milkim — лендинг студии перманентного макияжа (Омск)

Одностраничный сайт студии **Milkim**, мастер Анастасия Мильвиц.
Статическая сборка на Astro: на выходе обычная папка `dist/`, которую кладут на
любой хостинг по FTP или SSH. Ни серверных функций, ни базы данных.

---

## Быстрый старт

```bash
npm install
npm run dev        # локальный сервер на http://localhost:4321
```

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | дев-сервер с горячей перезагрузкой, порт 4321 |
| `npm run build` | сборка в `dist/` |
| `npm run check` | проверка типов и разметки (`astro check`) |
| `npm run serve` | отдаёт `dist/` **с gzip** на порту 4173 |
| `npm run verify` | замер бюджетов, скриншоты в `.verify/` |
| `npm run cases` | проверка портфолио: файлы на месте, размеры совпадают |
| `npm run cases -- --fix` | то же, но сначала подставляет настоящие размеры фото |

**Важно:** замерять вес страницы можно только через `npm run serve`.
Обычные статические серверы (`serve`, `http-server`, `python -m http.server`) не
сжимают ответ, и цифры получаются завышенными примерно вдвое.

Порядок перед публикацией:

```bash
npm run cases                                     # если трогали портфолио
npm run check && npm run build && npm run serve   # в одном терминале
npm run verify                                    # в другом
```

Так их потом можно будет отдать в админку без переписывания вёрстки.

## Как поменять типовые вещи

**Цену.** `src/content/prices.json`, поля `base` и `correction`, в рублях числом.
Цены на сайте обязаны совпадать с карточками в 2ГИС и на Авито.

**Телефон, адрес, часы, ссылки.** `src/data/site.json`.
Если очистить `links.max`, кнопка MAX пропадёт с первого экрана и из контактов сама.

**Вопрос в FAQ.** `src/content/faq.json` — объект с `id`, `q`, `a`.

**Добавить работу в портфолио.**
1. Положить фотографии в `src/assets/portfolio/brows/12/` (или `correction/09/`).
2. Добавить запись в `src/content/cases.json`:

```json
{
  "id": "brows-12",
  "service": "brows",
  "serviceTitle": "Брови",
  "number": 12,
  "layout": "collage",
  "frames": [{ "file": "brows/12/collage.jpg", "w": 1024, "h": 1024 }]
}
```

`layout` бывает трёх видов:

| `layout` | Что показывает |
|---|---|
| `collage` | один готовый коллаж «до и после» одним кадром — как делает студия |
| `pair` | два отдельных кадра рядом; у каждого кадра нужен `"role": "before"` или `"after"` |
| `single` | одна фотография результата (когда кадра «до» не существует) |

3. Выполнить `npm run cases -- --fix` — скрипт сам проставит настоящие `w` и `h`
   и скажет, если что-то не так.

Разметку трогать не нужно. Подробности и примеры — в `docs/portfolio.md`.

## Что нельзя менять — это не стиль, а обязательства

- **Только настоящие фотографии студии** там, где показан результат. Никаких стоковых
  и сгенерированных лиц, бровей, губ и «до/после». Это и доверие, и юридический риск
  в рекламе косметологической процедуры.
- **Никакого Instagram и Facebook** — ни встроек, ни иконок, ни ссылок.
- **Никаких обещаний результата**: перекрыть любой пигмент, гарантированный цвет,
  фиксированное число сеансов, «совсем не больно». Противопоказания и необходимость
  консультации должны оставаться на странице.
- **Отзывы — только реальные, с указанием площадки.**
- Каждая заглушка должна быть видна как заглушка: в имени файла `placeholder`,
  на элементе `data-placeholder="true"` и видимая пометка в вёрстке.

Подробный свод правил, бюджетов и решений клиента — в `CLAUDE.md`.

## Работа в другой нейросети

Проект собран так, чтобы его можно было отдать любому ИИ-ассистенту, который умеет
читать репозиторий и запускать команды. Порядок:

1. Дать доступ к репозиторию.
2. Скопировать в первое сообщение текст из **`docs/ai-brief.md`** — это готовый бриф
   с правилами, командами и границами.
3. Дальше просто формулировать задачи обычными словами.

Ассистент должен в первую очередь прочитать `CLAUDE.md` — там весь свод правил,
решения клиента и бюджеты, — а перед правкой портфолио ещё и `docs/portfolio.md`.

## Публикация

`npm run build` — и содержимое папки `dist/` кладётся в корень сайта на хостинге.
Перед первой публикацией нужно вписать настоящий домен в `astro.config.mjs`
(поле `site`) — от него считаются канонический адрес и ссылка на `og:image`.
