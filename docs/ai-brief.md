## Что это технически

Astro 7, статическая сборка (`output: 'static'`), на выходе обычная папка `dist/`.
Свой CSS с переменными, без фреймворков. Компоненты `.astro`, UI-библиотек нет.
Картинки обрабатывает встроенный пайплайн Astro (sharp) в AVIF.

Команды:

```
npm install
npm run dev                # локальный сервер, порт 4321
npm run check              # проверка типов и разметки
npm run cases              # проверка портфолио
npm run cases -- --fix     # то же, но сначала проставляет размеры фото
npm run build              # сборка в dist/
npm run serve              # отдаёт dist/ с gzip на порту 4173
npm run verify             # замер бюджетов и скриншоты
```

## Главное правило по содержимому

**Все тексты, цены, отзывы, вопросы и список работ лежат в `src/content/` и
`src/data/site.json`.** Никогда не вписывай текст или цену прямо в разметку —
это сломает план по подключению админки.

| Что менять | Файл |
|---|---|
| Цены | `src/content/prices.json` |
| Что входит в стоимость | `src/content/included.json` |
| Вопросы и ответы | `src/content/faq.json` |
| Памятка по уходу | `src/content/aftercare.json` |
| Противопоказания | `src/content/contraindications.json` |
| Отзывы | `src/content/reviews.json` |
| Работы в портфолио | `src/content/cases.json` |
| Адрес, телефоны, часы, ссылки, реквизиты, акция | `src/data/site.json` |

## Чего нельзя делать никогда

- **Не ставить стоковые, чужие или сгенерированные ИИ изображения лиц, бровей, губ
  и любых «до/после».** Каждый кадр с результатом — настоящее фото студии. Это не
  вкусовщина: на этом держится доверие к мастеру, и это юридический риск в рекламе
  косметологической процедуры. Абстрактная фактура (свет, ткань, пигмент в жидкости)
  — можно, человек и результат — нет.
- **Не добавлять Instagram и Facebook** — ни встроек, ни иконок, ни ссылок, ни
  пикселей. В России они для рекламы непригодны.
- **Не обещать результат.** Нельзя писать, что можно перекрыть любой старый пигмент,
  гарантировать цвет, называть точное число сеансов или обещать, что совсем не больно.
  Упоминание противопоказаний и необходимости консультации должно остаться на странице.
- **Не выдумывать содержимое.** Нет материала — ставь заглушку, видимую как заглушка
  (`data-placeholder="true"` плюс заметная пометка), и скажи мне, чего не хватает.
- **Не ставить Яндекс Карты** — убраны с сайта намеренно. Вместо них ВКонтакте и 2ГИС.
- **Не возвращать анимации в блок работ.** Их убрали, потому что девятнадцать карточек
  со scroll-анимациями подвешивали перелистывание на телефоне.
- **Не подключать новые библиотеки, шрифты и внешние скрипты, не спросив меня.**
  Сначала покажи команду и объясни, зачем.
- **Не настраивать хостинг, домен и деплой** — этого пока не делаем.

## Требования, которые надо удержать

- **Мобильный экран главнее.** Сначала делаем и проверяем на ширине 375 px, потом
  расширяем.
- **Только русский язык**, валюта `₽` после числа через неразрывный пробел: `5 500 ₽`.
  Кавычки «ёлочки», тире — длинное (—), без КАПСА в тексте.
- **Доступность:** видимый фокус с клавиатуры, альтернативный текст у каждой значимой
  картинки, кликабельные элементы не меньше 44×44 px, контраст по WCAG 2.2 AA.
- **Страница обязана читаться с выключенным JavaScript.**
- **Любая анимация уважает `prefers-reduced-motion`.**
- **Бюджеты производительности** — раздел 4 в `CLAUDE.md`. Главные: LCP не больше
  2,5 с, CLS не больше 0,1, первый экран не больше 600 КБ, JS на первой загрузке
  не больше 40 КБ.

## Как проверять свою работу

Не на глаз. После правок:

```
npm run cases     # если трогал портфолио
npm run check
npm run build
npm run serve     # в одном терминале
npm run verify    # в другом
```

`npm run verify` печатает PASS / WARN / FAIL по каждому бюджету и делает скриншоты
в трёх режимах: обычном, с `prefers-reduced-motion` и с выключенным JavaScript.
Меряй только через `npm run serve` — остальные статические серверы не сжимают ответ,
и цифры получаются завышенными примерно вдвое.

Известное состояние на момент передачи: LCP около 2,35 с (WARN, в пределах лимита —
это осознанная плата за заставку при открытии), CLS 0, первый экран около 200 КБ,
15 запросов, JS 0 КБ.
