# MILKIM — пакет логотипа для дизайнера и производства

Основа: последний вариант с волнами вместо цветов, рыбкой слева внизу, толстыми локонами и более тонкими остальными линиями. Дата пакета: 06.09.2026.

## Быстрый выбор
- Печать визиток, сертификатов, буклетов: 02_PRINT_PDF. Это векторные элементы для размещения в макете.
- Вывеска и крупная печать: SVG или PDF. Для резки/гравировки технолог проверяет контуры и минимальные перемычки.
- Золотая фольга: PDF с суффиксом foil_separation; содержит отдельную плашку Gold_Foil для всей графики, включая надпись.
- Одноцветная печать, штамп, гравировка: black.pdf / black.svg. Для старых программ есть черные EPS.
- Сайт, соцсети, наложение на фото: PNG с прозрачностью, 3000 px по ширине.
- Быстрый просмотр и отправка: JPG или gold_on_black.png.

## Состав и названия
full = полный вертикальный логотип; emblem = круглый знак без текста; wordmark = MILKIM с подписью без знака.
gold_on_black = золото на черной подложке; gold_transparent = золото без подложки; black = полностью черная графика без подложки; white = полностью белая графика без подложки.
Белые SVG/PNG/PDF на белой странице могут выглядеть пустыми: размещайте на темном фоне.

01_VECTOR_SVG: 12 настоящих векторных файлов, буквы в контурах, установки шрифтов не требуется.
02_PRINT_PDF: 15 векторных PDF: 4 цветовых исполнения + отдельная плашка фольги для каждого из 3 форматов.
03_PNG: 12 PNG с шириной 3000 px, плюс JPG полного логотипа. Белые/черные/золотые варианты без фона имеют альфа-канал.
04_SOURCE: исходный утвержденный растр, 1254 × 1254 px.
05_GUIDE: иллюстрированная инструкция, варианты и размерная проба.
06_EPS: 3 векторных черных EPS для совместимости.

## Цвет
SVG/PNG: золото #F3CF83, светлая подпись #F4F1E8, фон #000000. Цвет нормализован для плоского воспроизведения.
PDF: процессное золото C0 M15 Y46 K5, светлая подпись C0 M1.2 Y5 K4; фон K100. Это стартовая рецептура, не результат цветопробы и не профиль конкретной машины.
PDF foil_separation: плашка Gold_Foil, 100%, без фоновой заливки; экранный альтернативный цвет черный. Цвет фольги выбирается по физическому образцу.
Обычный CMYK воспроизводит золотистый оттенок, но не металлический блеск. Для металлического эффекта нужен отдельный материал/технология.

## Размер и ограничения
PDF имеет ширину страницы 100 мм; масштабируется пропорционально. SVG масштабируется без пикселизации. PNG 3000 px при 300 ppi соответствует 254 мм ширины файла; это экспорт с вектора, а не новая детализация исходного рисунка.
Вектор получен автоматической трассировкой исходного растра с визуальной проверкой. Это настоящие кривые, но не ручная геометрическая реконструкция: возможны мелкие неровности и изменения контуров. Исходник сохранен для сравнения.
Спираль, ресницы, пальцы и подпись содержат тонкие детали. Для мелкой фольги, резки пленки, штампа и лазера технолог должен проверить минимальные линии, зазоры и технологические ограничения. Не отправляйте файл прямо на станок как готовую траекторию реза.
На маленькой визитке лучше использовать отдельный знак и отдельный текстовый блок. Полный логотип при ширине 30–35 мм дает очень мелкую подпись. Подпись при необходимости набирается дизайнером отдельно крупнее в макете; геометрия утвержденного полного логотипа в пакете не менялась.
PDF не объявлены PDF/X, не имеют универсального профиля печатной машины и не являются готовыми макетами визитки/вывески. Вылеты, TrimBox, размеры изделия, контакты и фон до края добавляются при подготовке конкретного изделия по требованиям исполнителя.

## Что передать для финального макета
Визитка: формат и ориентация, имя/должность, телефон, адрес, ссылки и цель QR-кода, одна или две стороны, бумага и отделка.
Вывеска: размеры, фото места, материал, подсветка, способ производства.
Типография: файл SVG/PDF + эта инструкция; запросить проверку мелких линий, профиль, вылеты, требования к фольге и цветопробу.
AI/CDR не созданы: это форматы конкретных редакторов. Переданные SVG/PDF/EPS содержат векторные контуры для импорта. TIFF не обязателен при наличии векторного PDF; экспортируют под размер и профиль конкретного заказа.
